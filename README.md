### 阶段二：项目八——面向特定人群的低成本智能交互辅具研发

**项目目标：** 面向老年人、视听障碍人士等群体，围绕服药提醒、环境声音提示和安全倒水等日常场景，设计低成本、易上手、可离线工作的交互辅具。设计重点不只是增加功能，还包括降低误操作、提供清晰反馈，并让用户在受限条件下也能独立完成任务。

#### 原型方案

| 原型 | 面向场景 | 主要交互思路 |
|---|---|---|
| D1 智能药盒提醒器 | 老年人服药提醒 | 通过语音、灯光、触觉标记和开盖状态提示服药时段，并尽量减少选错药仓和误确认 |
| D2 环境声振动提示手环 | 听障人士感知敲门、水开等环境声音 | 识别特定环境声音，以不同振动节奏传递提示 |
| D3 防烫水杯引导器 | 视障人士安全倒水 | 以非视觉反馈辅助判断水位或倒水状态，降低烫伤风险 |

#### 阶段性验证

评审版报告记录了三类受限条件下的盲操测试：单手操作、蒙眼模拟视障、佩戴降噪耳塞模拟听障。每个“原型 × 条件 × 轮次”测试 30 次；指标表共记录 16 组、合计 480 次试验。R0 至 R3 的成功率变化如下：

| 原型与测试条件 | R0 成功率 | R3 成功率 | R0 → R3 中位耗时 |
|---|---:|---:|---:|
| D1 药盒 · 单手 | 63% | 97% | 41.2 秒 → 13.7 秒 |
| D1 药盒 · 蒙眼 | 43% | 93% | 42.5 秒 → 13.6 秒 |
| D1 药盒 · 降噪耳塞 | 70% | 97% | 36.8 秒 → 11.6 秒 |
| D2 手环 · 降噪耳塞 | 70% | 93% | 25.4 秒 → 10.5 秒 |
| D3 水杯引导器 · 蒙眼 | 53% | 97% | 40.0 秒 → 13.8 秒 |

报告还记录了三台原型物料合计 **174 元**。以上数字是当前评审版报告和 [`06_迭代_轮次指标.csv`](./02-Days-Challenge/06_迭代_轮次指标.csv) 中的阶段性记录；受限条件为模拟测试，仓库目前没有完整的逐次原始试验记录及报告提到的访谈材料，因此这些结果不应视为真实用户研究结论或产品安全验证。

## Git 基本流程

在仓库目录中执行以下命令。首次使用时，先确认 Git 已安装并完成身份配置。

```bash
git status
git add .
git commit -m "记录本次项目进展"
git push origin main
git log --oneline
```

- `git status`：查看文件修改状态。
- `git add .`：暂存当前目录下的修改；提交前请检查暂存内容。
- `git commit`：将暂存内容保存为本地版本记录。
- `git push origin main`：将 `main` 分支推送到 GitHub。
- `git log --oneline`：查看精简提交历史。

学习资源：[Learn Git Branching（中文版）](https://learngitbranching.js.org/?locale=zh_CN) · [GitHub 中文文档](https://docs.github.com/zh)
