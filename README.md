## Git 基本流程

在仓库目录中执行以下命令。首次使用时，先确认 Git 已安装并完成身份配置。

```bash
git status
git add .
git commit -m "记录本次实验进展"
git push origin main
git log --oneline
```

- `git status`：查看文件修改状态。
- `git add .`：暂存当前目录下的修改。
- `git commit`：将暂存内容保存为本地版本记录。
- `git push origin main`：将 `main` 分支推送到 GitHub。
- `git log --oneline`：查看精简提交历史。

学习资源：[Learn Git Branching（中文版）](https://learngitbranching.js.org/?locale=zh_CN) · [GitHub 中文文档](https://docs.github.com/zh)
