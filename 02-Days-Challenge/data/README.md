# 逐次试验数据

## 当前状态

仓库目前包含迭代变更表和轮次指标汇总表，但没有支撑这些汇总结果的逐次试验原始记录。请不要将空白模板、汇总数据或模拟数据误认为真实试验记录。

## 模板

- [盲操逐次试验 CSV 模板](./04_盲操_原始数据_模板.csv)：每一行对应一次任务试验。

开始正式记录前，先在过程日志中写明测试日期、任务步骤、设备/原型版本、条件定义、参与者匿名编号和数据处理规则。每次试验填写一行；不适用或未采集的字段留空并说明原因，不得推测补齐。原始数据应只追加、不覆盖；修正时保留原文件并另存版本。

模板字段中的匿名编号不得使用姓名、学号、手机号等可识别个人身份的信息。

## 字段填写约定

- `task_success`、`success_first_try`、`error_corrected` 使用 `1` 表示是、`0` 表示否；无法确认时留空并说明。
- `assistance_count` 填写任务中接受的协助次数；`elapsed_seconds` 使用秒。
- `condition`、`round` 和 `prototype_version` 应在同一轮测试中使用一致的命名，并在过程日志中解释其含义。
- 测试成功标准应在开始前定义；不要在看到结果后调整口径。
