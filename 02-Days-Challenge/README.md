# 阶段二：项目八——面向特定人群的低成本智能交互辅具研发

## 项目目标

围绕老年人、视听障碍人士等人群的日常需求，探索低成本、易上手、可离线工作的智能交互辅具。当前项目关注服药提醒、环境声音提示和安全倒水三类场景，设计时重点考虑受限条件下的操作成功率、误操作纠正和多通道反馈。

## 原型与当前方案

| 原型 | 目标场景 | 当前设计方向 |
|---|---|---|
| D1 智能药盒提醒器 | 老年人服药提醒 | 结合语音、灯光、触觉标记及开盖状态提示，减少选错药仓和误确认 |
| D2 环境声振动提示手环 | 听障人士感知敲门、水开等环境声音 | 识别特定环境声音，并以不同振动节奏传递提示 |
| D3 防烫水杯引导器 | 视障人士安全倒水 | 以非视觉反馈辅助判断水位或倒水状态，降低烫伤风险 |

三台原型的物料成本合计为 174 元（评审版报告记录）。具体物料清单、接线、结构文件和程序版本应随原型材料一并补充，便于他人复现。

## 阶段性测试结果

评审版报告记录了单手操作、蒙眼模拟视障、佩戴降噪耳塞模拟听障三种受限测试条件。每个“原型 × 条件 × 轮次”记录 30 次；指标表共 16 组、480 次试验。

| 原型与测试条件 | 轮次 | 成功率变化 | 中位耗时变化 |
|---|---|---:|---:|
| D1 药盒 · 单手 | R0 → R3 | 63% → 97% | 41.2 秒 → 13.7 秒 |
| D1 药盒 · 蒙眼 | R0 → R3 | 43% → 93% | 42.5 秒 → 13.6 秒 |
| D1 药盒 · 降噪耳塞 | R0 → R3 | 70% → 97% | 36.8 秒 → 11.6 秒 |
| D2 手环 · 降噪耳塞 | R0 → R3 | 70% → 93% | 25.4 秒 → 10.5 秒 |
| D3 水杯引导器 · 蒙眼 | R0 → R3 | 53% → 97% | 40.0 秒 → 13.8 秒 |

以上为评审版报告和汇总指标表中的阶段性结果。模拟受限条件不等同于真实用户研究；当前仓库缺少逐次原始试验记录及报告提及的访谈材料，结果仍需补充证据后复核，不应作为产品安全性或真实用户可用性的结论。

## 迭代方法与待解决问题

迭代时根据操作中出现的问题定位原因，优先考虑物理结构防呆，再补充感知提示和出错后的纠正反馈。迭代记录也保留了改动引入的新问题，后续需要通过针对性复测验证。

现有记录显示，R3 后仍需关注：

- 药盒仓盖在侧放或携带时可能未能可靠复位。
- 厚衣物会削弱手环振动，影响不同提示节奏的辨识。
- 成功率之外，还需要关注一次做对率、自我纠正率、协助次数和测试耗时。

1. 补充逐次试验记录、测试脚本/步骤、原型版本与数据处理方法，保证指标可追溯。
2. 补充电路图、物料清单、固件/程序和结构文件，说明原型如何复现。
3. 针对上述 R3 问题设计下一轮改动，并使用一致的测试条件复测。
4. 在知情同意、安全和隐私保护前提下开展真实场景验证；模拟测试不能替代真实用户参与或产品安全评估。
