# 课题 08：多姿态步态加速度特征采集与对比

- [数据分析材料目录](./analysis/README.md)：当前尚无特征处理脚本和基于实测数据的判别结果

## 实验概述

使用手机加速度计采集静止、平地慢走、快跑和上下楼梯等姿态的三轴加速度，提取时域、频域及波形形状特征，并建立可解释的分层阈值规则。

## 采集方案

- 工具：Phyphox 或其他可导出三轴加速度的传感器应用
- 采样率：100 Hz
- 单次时长：每种状态 40 s
- 放置位置：右前裤袋，手机竖直放置，屏幕贴向大腿
- 坐标约定：+Y 向上，+X 指向行进方向，+Z 指向身体右侧
- 建议重复：每种状态至少采集 3 次，并采用稳定版本作为正式数据

## 当前结果

已整理的报告采用静止、慢走、快跑、上下楼梯四组参考波形，在 100 个滑动窗口上得到 100.0%的判别准确率。该满分属于同一物理模型生成的规范数据；实际采集时应使用重复实测验证，并考虑佩戴方式、个体步态、场地和手机姿态造成的误差。

## 安全提示

快跑、上下楼梯和重复采集时应佩戴稳固鞋具，选择非拥挤且不湿滑的场地，避免边看手机边移动。采集设备损坏或人员摔倒风险高时应立即停止。
