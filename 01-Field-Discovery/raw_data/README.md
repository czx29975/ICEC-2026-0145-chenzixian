# 原始数据

将阶段一采集的未经处理原始数据放在此目录。过程照片仍按课题归档在各自课题文件夹中。建议按课题和日期命名数据文件，例如：

```text
topic02-2026-10-24-phone-temperature.csv
topic08-2026-10-24-walking-accelerometer.csv
```

请勿覆盖原始文件；整理或清洗后的副本请另行保存，并在过程记录中说明。提交前检查并脱敏个人信息。

## 空白数据模板

- [课题 02：手机发热与掉电](./topic02-phone-thermal-power-template.csv)：每行记录一个采样时点。
- [课题 08：步态加速度](./topic08-gait-accelerometer-template.csv)：每行记录一个传感器采样时点。

模板只定义建议字段，不含真实数据。采集设备无法提供的字段可留空，并在备注中说明；不要用估算值补齐。
