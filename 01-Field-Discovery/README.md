## 报告数据说明

报告中的课题 02 数据明确标注为物理模型仿真数据，课题 08 的分类满分也基于同一模型生成的规范波形。因此，这两份报告目前适合作为方案、指标体系、分析流程和图表模板；正式结论必须替换为真实采集与重复验证的数据。

## 记录建议

- 先记录实验目的、设备与环境、变量、步骤和安全注意事项。
- 原始文件放入 [`raw_data/`](./raw_data/)，按日期和课题区分；空白字段模板见[课题 02](./raw_data/topic02-phone-thermal-power-template.csv)和[课题 08](./raw_data/topic08-gait-accelerometer-template.csv)。
- 保留未经修改的原始数据；清洗、转换后的文件另存并记录处理方式。
- 照片或数据中如含个人信息，请在分享前进行脱敏。

模板只有字段标题，不包含实验数据。当前仓库尚无这两项课题的逐次原始采集数据；请实际采集后再填写，不要把报告中的模型数据当作真实测量值。
